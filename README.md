# Smirnov Prod. — Portfolio Website

A cinematic video editing portfolio built with React + Vite + Tailwind CSS.

## Setup
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

## Deploy to Netlify
1. Push to GitHub
2. Go to netlify.com → New site from Git
3. Build command: `npm run build`
4. Publish directory: `dist`
